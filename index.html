About

I have spent four years learning offensive security on my own, with a focus on red teaming. My work covers adversary simulation, network and web application exploitation, Active Directory attack paths, AWS security, and binary exploitation, using Nmap, Metasploit, Burp Suite, BloodHound, and GDB.

My approach is methodical: understand how a system is designed to work, identify the assumptions it relies on, then test whether those assumptions hold. I follow the same path on every engagement: recon, enumeration, exploitation, privilege escalation, pivoting, and reporting.

I research public CVEs and write proof-of-concept exploits for them. I also build my own security tools in Python, such as SSRF and SSTI tools, to understand how these bugs really work. I practice regularly on TryHackMe and Hack The Box. I am studying Software Engineering and aiming to grow into a Cybersecurity Engineer role, where I can apply red team and vulnerability assessment skills to strengthen an organization's security.

Currently learning: AWS privilege escalation, network pivoting, and heap exploitation. Open to: CTF teams and collaboration on cloud security research.
